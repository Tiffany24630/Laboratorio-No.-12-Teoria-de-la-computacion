# Laboratorio-No.-12-Teoria-de-la-computacion
La solución está separada por problema:

- `problema2.js`: ordenamiento de objetos.
- `problema3.js`: transposición de matrices.
- `problema4.js`: eliminación de elementos.
- `lab12.js`: archivo general que contiene los datos de prueba y ejecuta todos los problemas.

## Requisitos
- Node.js 18 o superior (no requiere instalar dependencias).

## Ejecución
Desde esta carpeta:

```bash
node lab12.js
```

Para usar una solución individual desde otro archivo:

```js
const { ordenarPor } = require("./problema2");
```
